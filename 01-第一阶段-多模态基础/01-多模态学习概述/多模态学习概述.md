# 多模态学习概述

## 什么是多模态学习

多模态学习（Multimodal Learning）让模型同时理解图像、文本、语音、视频或动作等不同信息形式。目标不是分别处理每种输入，而是利用模态之间的互补关系完成理解、生成与决策。

图像提供外观和空间关系，文本表达抽象概念、意图和细粒度约束。结合后，模型可以完成图文检索、视觉问答和图像描述。

## 常见任务

| 任务 | 输入 | 输出 |
| --- | --- | --- |
| 图文检索 | 图像或文本 | 对应的另一模态样本 |
| 零样本分类 | 图像 + 类别文本 | 类别 |
| 图像描述 | 图像 | 文本 |
| 视觉问答 | 图像 + 问题 | 答案 |
| 视觉定位 | 图像 + 文本 | 框或掩码 |

## 融合方式

1. **早期融合**：在输入或浅层拼接特征，交互充分但要求较强对齐。
2. **晚期融合**：各模态独立建模，最后融合预测，简单但跨模态推理较弱。
3. **中间融合**：分别编码，再通过交叉注意力或共享表征空间交互，是现代 VLM 的主流。

## 基本范式

```text
图像 -> 图像编码器 -> 图像向量 --┐
                                ├-> 对齐 / 融合 -> 下游任务
文本 -> 文本编码器 -> 文本向量 --┘
```

图文对比学习会把匹配图文映射到相近的向量位置，把不匹配样本拉远。CLIP 与 SigLIP 都属于这一范式。

## 学习重点

- 模态如何被转换为 token 或向量。
- 图文配对数据的来源、噪声与偏差。
- 对比学习的正样本、负样本和温度系数。
- 表征学习与生成式建模的区别。
