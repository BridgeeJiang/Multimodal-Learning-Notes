# 图文对齐

## 目标

图文对齐（Image-Text Alignment）学习一个共享语义空间：匹配的图像和文本特征相似，不匹配的特征不相似。训练后即可比较任意图像和文本的相似度。

## 双编码器

最常见的结构包含图像编码器 `f(I)`（如 ResNet、ViT）和文本编码器 `g(T)`（如 Transformer）。二者投影到同一维度并做 L2 归一化：

```text
v = normalize(f(I))
t = normalize(g(T))
s(I, T) = v · t
```

归一化后，点积等于余弦相似度。双编码器可离线索引图像或文本，适合大规模检索。

## 批内对比学习

一个 batch 有 `N` 对图文 `(I_i, T_i)`。第 `i` 对是正样本，其他组合通常是负样本。CLIP 使用对称的 InfoNCE 损失：

```text
L_image = -mean_i log exp(s(i,i)/τ) / sum_j exp(s(i,j)/τ)
L_text  = -mean_i log exp(s(i,i)/τ) / sum_j exp(s(j,i)/τ)
L = (L_image + L_text) / 2
```

`τ` 是温度参数，控制相似度分布的尖锐程度。

## 数据与难点

- 网页 alt-text、标题和描述规模大，但常含噪声。
- 不同文本可能都正确描述同一类图像，形成假负样本。
- 文本可能描述整图，而图像包含多个对象，粒度并不一致。
- 数据分布会影响公平性、语言覆盖和长尾能力。

## 实践清单

1. 确认图像、文本预处理与预训练一致。
2. 检查特征是否归一化，温度是否可学习。
3. 计算完整 `N × N` 相似度矩阵。
4. 同时计算图到文、文到图两个方向的损失。
5. 查看检索样例，而不只看平均指标。
