# CLIP

## 一句话概括

CLIP（Contrastive Language-Image Pre-training）使用大规模图文对进行对比学习，将图像和文本映射到共享语义空间。它不针对单一类别训练，因此可借助自然语言提示词完成零样本分类与检索。

## 模型结构

```text
图像 -> ResNet / ViT -> 图像投影 -> 归一化图像向量
文本 -> Transformer  -> 文本投影 -> 归一化文本向量
                                      ↓
                              图文相似度矩阵
```

- 图像编码器可以是 ResNet 或 ViT。
- 文本编码器是 Transformer，通常取序列末尾特殊 token 的特征。
- 两路特征投影到同一维度后，以余弦相似度计算配对分数。

## 训练目标

对包含 `N` 对图文的 batch，构造 `N × N` 相似度矩阵。对角线表示正确配对，非对角线表示不匹配组合。CLIP 对图像到文本和文本到图像各计算一次交叉熵，再取平均。

更大的 batch 会带来更多负样本，同时增加显存和分布式通信成本。

## 零样本分类

将类别写成提示词，例如 `a photo of a {class}`。编码所有类别文本后，输入图像分别与它们计算相似度，最高分对应预测类别。实践中可用多个模板并平均文本特征，减小措辞影响。

## 优势与局限

**优势**：开放词汇、迁移能力强，可直接用于检索和零样本分类。

**局限**：对细粒度空间关系、计数、文字识别和长链推理较弱；网页图文数据也会引入噪声、偏差与版权风险。

## 代码阅读重点

1. 图像和文本预处理是否与预训练一致。
2. 特征归一化是否发生在相似度计算之前。
3. `logit_scale` 对应温度的倒数，通常是可学习参数。
4. 标签是相似度矩阵的对角线索引 `0 ... N-1`。

## 练习

- 使用预训练 CLIP 在小型图像集上实现零样本分类。
- 比较不同 prompt 模板的分类结果。
- 输入文本，返回相似度最高的若干图片。
