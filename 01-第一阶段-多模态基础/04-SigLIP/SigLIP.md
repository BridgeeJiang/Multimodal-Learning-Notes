# SigLIP

## 与 CLIP 的区别

SigLIP（Sigmoid Loss for Language Image Pre-Training）和 CLIP 都使用双编码器学习图文共享表示，但训练目标不同：CLIP 对整行或整列相似度做 softmax；SigLIP 把每一个图文组合视为独立的二分类问题，使用 sigmoid loss。

## Sigmoid 损失

对图像 `i` 和文本 `j`，令 `z_ij` 是缩放、偏置后的相似度，`y_ij` 为配对标签：匹配时为 `+1`，不匹配时为 `-1`。单个组合的损失为：

```text
L_ij = -log sigmoid(y_ij · z_ij)
```

总损失对 batch 内所有图文组合求平均；它不要求每一行或每一列的概率和为 1。

## 为什么有用

- 每个图文对独立优化，减少了对全局 batch 归一化的依赖。
- 对分布式训练更友好，通常可用较小 batch 获得良好效果。
- 可学习的缩放与偏置有助于校准正、负样本的决策边界。

## 仍需注意

SigLIP 没有消除数据质量、假负样本或跨语言覆盖问题。编码器、数据规模和训练配方仍会显著影响最终效果。推理时它仍通过图文相似度完成分类与检索。

## CLIP 与 SigLIP 对比

| 维度 | CLIP | SigLIP |
| --- | --- | --- |
| 损失 | softmax 对比损失 | sigmoid 二元损失 |
| batch 内关系 | 候选文本互相竞争 | 每个图文组合独立判别 |
| 校准 | 温度缩放 | 缩放与偏置 |
| 用途 | 分类、检索 | 分类、检索、表征学习 |
