# MoCo 方法讲解

MoCo（Momentum Contrast）是一种自监督表征学习方法，核心目标是：**不依赖人工标签，让模型学会把“相似的图片”映射到相近的特征空间位置。**

它将每张图片做两种随机增强，视为同一个样本的两个视图：

- 原图经过增强 A → 查询向量 `q`
- 原图经过增强 B → 正样本向量 `k+`
- 其他图片的向量 → 负样本 `k-`

训练时使用对比学习损失，让 `q` 更接近 `k+`，远离所有 `k-`：

对比学习损失：

`L = -log( exp(q · k+ / τ) / (exp(q · k+ / τ) + Σ exp(q · ki- / τ)) )`

其中，`τ` 是温度系数，用来调节相似度分布的尖锐程度。



## 核心设计

### 1. 动量编码器（Momentum Encoder）

MoCo 使用两个编码器：

- **Query Encoder**：正常通过反向传播更新，产生查询向量 `q`。
- **Key Encoder**：不直接参与反向传播，而是通过 Query Encoder 参数的指数滑动平均更新。

动量编码器更新公式：

`θk ← m · θk + (1 - m) · θq`

其中：

- `θq`：Query Encoder 的参数
- `θk`：Key Encoder 的参数
- `m`：动量系数，通常接近 `1`，例如 `0.999`

Key Encoder 更新较慢，因此它生成的特征更加稳定。

### 2. 负样本队列（Queue / Dictionary）

对比学习通常需要大量负样本，但增大 batch size 会显著占用显存。

MoCo 将历史 batch 产生的 Key 特征存放在一个队列中：

- 当前 batch 的 Key 特征入队；
- 队列中最旧的特征出队；
- 队列中的大量历史特征作为负样本。

因此，即使 batch size 不大，MoCo 也可以获得大量负样本。

## 整体流程

```
同一张图像
 ├─ 增强视图 1 → Query Encoder → q
 └─ 增强视图 2 → Momentum Key Encoder → k+

队列中其他图像的特征 → k1-, k2-, ...

训练目标：q 接近 k+，远离所有负样本
```

## MoCo 解决的问题

早期对比学习方法通常需要非常大的 batch size，才能获得足够多的负样本。

MoCo 通过以下两个机制解决该问题：

1. 使用队列保存历史样本特征，提供大量负样本；
2. 使用动量编码器，使队列中不同时间产生的特征保持一致和稳定。

## 训练后的使用方式

MoCo 预训练完成后，通常会：

- 移除队列；
- 不再使用 Key Encoder；
- 保留训练好的 backbone 作为特征提取器；
- 将其迁移到下游任务中。

常见下游任务包括：

- 图像分类
- 目标检测
- 语义分割
- 图像检索
- 少样本学习

## MoCo 的版本演进

- **MoCo v1**：提出动量编码器和负样本队列。
- **MoCo v2**：加入更强的数据增强、MLP Projection Head、余弦学习率等设计，显著提升效果。
- **MoCo v3**：主要适配 Vision Transformer（ViT），进一步简化训练方案。

## 一句话总结

> MoCo 使用一个缓慢更新的动量编码器和一个保存历史特征的负样本队列，让模型在没有人工标签的情况下，通过比较图片的相似与差异来学习有效的视觉表示。
